title: Projects
description: Install the official Projects plugin to group tasks, checklists, context, and linked assets.
---

Projects is an official plugin distributed from `madeinwyo/bakin-bits-official`, not a core plugin bundled inside Bakin. Once installed, it contributes project routes, MCP/exec tools, task-context hooks, and CLI commands from its plugin manifest.

## How to Use Projects

- Track project status and checklist progress.
- Link checklist items to tasks when the work needs agent execution.
- Attach assets when specs, designs, notes, or reference files need to travel with the project.
- Promote checklist items into tasks when they become actionable.

## Operator Notes

Use projects for durable context. Use tasks for executable work.
