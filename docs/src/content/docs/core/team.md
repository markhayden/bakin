title: Team
description: Use Bakin team management to inspect, create, adopt, configure, start, stop, and organize agents.
---

The team plugin manages the agent roster and its relationship to OpenClaw. It surfaces agent profiles, runtime status, avatars, workspace files, skills, memory, package state, and teams.

## Operator Notes

- Use team views to understand which agents exist and what they are doing.
- Use package state to keep agent files and managed blocks aligned.
- Start and stop agents through Bakin when you want the operation reflected in the dashboard.
- Organize agents into teams when the roster becomes hard to scan.
