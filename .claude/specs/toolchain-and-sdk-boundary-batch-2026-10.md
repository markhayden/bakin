## Objective

Close three open tech-debt issues as four PRs, one branch each, cut sequentially from merged `main` in the main checkout, each with Codex review rounds (cap ~5, stop at approve) and green CI before merge. Priority is tech-debt reduction: this machine (and margo) are the only users, so no shims, no compatibility layers, no facades left behind for old import paths.

### User
