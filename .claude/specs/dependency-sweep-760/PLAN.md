# Implementation Plan: App dependency sweep (#760)

Spec: `SPEC.md` (approved 2026-10-03). Task checklist: `TODO.md`.

## Overview

Thirteen sequential PRs in a dedicated worktree move every dependency in the root
app, `docs/`, and `packages/adapter-pi` to today's latest, delete seven unused
packages, and leave a reusable runbook. Each PR is one rollback unit (squash
merge); commits inside a PR are the in-flight checkpoints. After every merge the
live 3737 server is restarted onto `main` so each change set soaks alone. A
Bits companion PR and three follow-up issues close the initiative.

## Architecture decisions (carried from SPEC §1)

- Latest-today targets; nothing forced past a declared peer range (no `overrides`).
- Toolchain first (TS 6, ESLint 10) so every later PR is gated by the final toolchain.
- One variable per commit where a dependency has ever interacted with the suite
  (happy-dom, react before ink, playwright separate from vitest).
- zod keeps its tilde (minor-branded types); Bits moves in lockstep afterwards.
- Pi SDK last, with a live post-merge check.
- Generated artifacts (vendor bundles, embedded-assets manifest, sharp pin,
  snapshots) are regenerated by their scripts and committed in the PR that moves
  the dependency.

## Working rhythm (every PR)

1. `cd ../bakin-wt-deps && git fetch && git checkout -b chore/deps-NN-<topic> origin/main && bun install`
2. Make the manifest change for ONE commit group; `bun install`; fix what breaks
   properly; commit (`bun.lock` included).
3. Repeat for the PR's other commit groups.
4. Regenerate artifacts if a browser dep moved: `bun run build:host && bun run build:assets-manifest`;
   commit `packages/host/public/vendor/*` is NOT tracked (verify with `git status`) —
   only `packages/host/src/api/_embedded-assets-static.ts` and any ratchet JSON are.
5. Gate (SPEC §3.2), one suite at a time. Record results in the PR body.
6. Append the coupling/blocker learned to `.claude/knowledge/dependency-sweeps.md`
   (PR1 creates it) and fix any doc the bump made wrong — same PR.
7. `gh pr create`, wait for CI, `gh pr merge --squash --delete-branch`.
8. Post-merge checkpoint (below).
