# Memory

Memory docs cover observability over the stored context Bakin and OpenClaw use. The memory plugin is primarily read-oriented and helps operators understand what agents know, what happened, and where context came from.

## What to Inspect

- audit events
- workspace memory
- gateway/session memory
- daily notes
- turns and checkpoints
- recent memory activity
- memory search health

## Operator Notes

- Use memory when work has disappeared into previous sessions or logs.
- Treat memory as diagnostic context, not as a replacement for task/project records.
- Use search and audit trails together when reconstructing what an agent did.
