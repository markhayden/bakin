# Operation

Start the server:

```sh
bakin start
```

Bakin listens on port `3737` by default. Set `PORT` to override it.

Check status:

```sh
bakin status
```

Run diagnostics:

```sh
bakin doctor
```

Update the binary:

```sh
bakin update
```

Stop a running instance:

```sh
bakin stop
```
