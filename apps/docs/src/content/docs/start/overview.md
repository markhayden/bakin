# Start Here

Bakin is a self-hosted control surface for agent work. It combines a dashboard, backend services, CLI commands, core plugins, and an SDK for extending the system.

These docs serve three audiences, in priority order:

- Operators installing and running Bakin.
- Plugin authors and agent authors extending Bakin.
- Contributors working in the open-source repository.

## Where to Go

- Install and run Bakin: [Install](/run/install/).
- Set up a new instance: [First-Time Setup](/run/first-time-setup/).
- Build a plugin: [Plugin Authoring](/extend/plugins/overview/).
- Write agent-facing packages: [Agent Authoring](/extend/agents/overview/).
- Find exact contracts: [Reference](/reference/).

## Version Model

`docs.makinbakin.com` documents the latest released Bakin version. Preview deployments may show unreleased docs for pull requests or release candidates.
