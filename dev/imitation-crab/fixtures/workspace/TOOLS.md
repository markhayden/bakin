# Available Tools

## Bakin MCP Tools
- `bakin_exec_log_progress` — Report task progress
- `bakin_exec_images_recommend` — Recommend image provider/model/surface route
- `bakin_exec_images_generate` — Generate images through the core images plugin
- `bakin_exec_post_discord` — Post to Discord channels
- `bakin_exec_get_paths` — Get content directory paths
- `bakin_exec_heartbeat` — Send agent heartbeat
